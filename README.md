Overview
The PECCNAL mechanism proposes a Coulomb-barrier-free nuclear reaction chain:

p + e⁻ → n + νe          (-1.293 MeV, INPUT — no Coulomb barrier!)
n + ²H  → ³H + p          (+2.220 MeV)
³H + ²H → ⁴He + n         (+17.600 MeV, D-T fusion)
n + ⁶Li → ⁴He + ³H        (+4.780 MeV, Li-6 capture)
────────────────────────────────
NET:                        +23.307 MeV per cycle (ideal)
Key insight: Step 1 involves a proton (+) attracting an electron (−).
Opposite charges attract → no Coulomb barrier.
